Sobre o Projeto

Este site reúne todas as atividades desenvolvidas ao longo do semestre durante a disciplina. O objetivo deste portfólio é apresentar a evolução dos conhecimentos adquiridos em programação, algoritmos, Python, inteligência artificial e resolução de problemas computacionais.

Entregas do Semestre

Março — Fundamentos de Programação

Diagnóstico inicial, quizzes de lógica e exercícios introdutórios.

Abril — Algoritmos e Python

Exercícios em Python, listas, arrays e resolução com inteligência artificial.

Maio — Engenharia e Solução de Problemas

Problemas de engenharia resolvidos utilizando diferentes abordagens computacionais.

Junho — IA Aplicada e Avaliação Crítica

Análise do portal alegrete.org, modularização de código e desenvolvimento assistido por IA.

Principais Aprendizados

  • Lógica de programação
  • Algoritmos computacionais
  • Programação em Python
  • Uso de LLMs no desenvolvimento
  • Resolução de problemas de engenharia
  • Versionamento com GitHub
  • Publicação com GitHub Pages
