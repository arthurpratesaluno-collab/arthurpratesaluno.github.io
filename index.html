PROJETO DESTAQUE DO SEMESTRE

Evolução Técnica: Sistema de Modificação de Motores

Objetivo: Unir conceitos de termodinâmica e mecânica veicular com programação, construindo um modelo em Python para simulação de modificações mecânicas (Tuning de Motores) e cálculo de ganho estimado de potência (CV) e torque.

Tecnologias: Python (Estruturas Condicionais, Loops e Funções), Claude.ai.

Resultado: Um script interativo que simula upgrades de Estágio (Stage 1, Stage 2) alterando parâmetros de pressão de turbo e injeção.

Evolução Técnica Relato Entrevistas
simulador_tuning_unipampa.py 
class Motor:
    def __init__(self, modelo, cv_original, torque):
        self.modelo = modelo
        self.cv = cv_original
        self.torque = torque

    def simular_upgrade(self, stage):
        if stage == 1:
            self.cv *= 1.15  # +15% de eficiência volumétrica via ganho eletrônico
            self.torque *= 1.12
        elif stage == 2:
            self.cv *= 1.35  # +35% de potência com alteração física de exaustão
            self.torque *= 1.28
        return self.cv, self.torque

# Exemplo de execução simulando conceitos físicos aplicados em código
motor_carro = Motor("2.0 Turbo", cv_original=200, torque=350)
novo_cv, novo_torque = motor_carro.simular_upgrade(stage=2)
print(f"Potência final estimada: {novo_cv:.1f} CV")
